# 선택의 다른 쪽 · 기회비용 실험실

야구와 콘서트 중 하나를 고르며 돈과 시간의 다른 쓰임을 살펴보는 중학교 사회 수업용 콘텐츠입니다. 교사가 화면을 조작하고 학생은 예측·발언·짝 대화·공책 기록으로 참여합니다.

## 실행

`index.html` 하나를 브라우저에서 엽니다. CSS, JavaScript, SVG 그림이 파일 안에 포함되어 인터넷 연결이나 설치 없이 실행됩니다. GitHub Pages에서도 별도 빌드 없이 사용할 수 있습니다.

## 고정된 상황

같은 토요일 오후에 야구 경기와 콘서트가 열립니다. 각각 관람할 돈은 있지만, 이동·관람 시간이 겹쳐 한 곳만 갈 수 있습니다. 실제 행사나 가격을 재현한 자료가 아닙니다.

## 수업 흐름 · 45분

| 장면 | 시간 | 중심 질문 |
| --- | --- | --- |
| 먼저 선택 | 5분 | 야구를 보러 갈까, 콘서트에 갈까? |
| 돈의 쓰임 | 12분 | 이 돈으로 다른 무엇을 할 수 있을까? |
| 시간의 쓰임 | 12분 | 이 시간에 다른 무엇을 할 수 있을까? |
| 함께 판단 | 10분 | 얻는 것과 포기하는 것을 함께 보면? |
| 내 말로 설명 | 6분 | 나는 어떤 이유로 선택할까? |

돈 장면에서 실제 지출과 돈의 다른 쓰임을, 시간 장면에서 같은 시간에 다른 행사에서 얻을 수 있었던 가치를 살펴봅니다. 명시적 비용·암묵적 비용은 별도의 버튼으로 공개합니다. 선택 자체에 정답을 부여하지 않고, 포기하는 가치까지 고려한 설명을 확인합니다.

## 교사 조작

- 첫 선택은 이후 장면에서 함께 살펴보는 예시입니다. 선택하지 않고 건너뛰면 야구 관람을 예시로 표시합니다.
- 학생의 응답을 카드에 반영한 후 별도의 공개 버튼을 누릅니다. 선택만으로 설명이나 다음 장면이 나타나지 않습니다.
- 돈·시간 장면은 자료 공개 → 응답 선택 → 포기한 기회 공개 → 개념 이름 공개 순서입니다.
- 마지막 선택은 처음과 달라도 괜찮습니다. 선택 이유는 선택적으로 짧게 입력할 수 있습니다.
- 위 단계 이름이나 ← / → 키로 이동합니다. 입력 중에는 장면 이동 단축키가 작동하지 않습니다.
- 첫 선택을 바꾸거나 지우면 돈·시간·비교 장면을 새 선택에 맞춰 초기화합니다. 마지막 설명은 유지합니다.
- 수업 안내에서 발문·개념 유의사항·전체 초기화를 확인할 수 있습니다.
- 기록은 페이지가 열려 있는 동안만 유지됩니다. 새로고침하면 초기화되며 외부로 전송되지 않습니다.

## 개념 설명 유의사항

명시적 비용은 실제 지출하는 돈입니다. 암묵적 비용은 자신의 자원을 사용하며 포기한 차선의 가치로, 이 수업에서는 시간의 다른 사용 기회를 통해 살펴봅니다. 두 개념을 돈과 시간에 각각 일대일 대응하는 고정된 등식으로 가르치지 않습니다.

기회비용은 선택 때문에 포기한 기회 중 가장 가치 있는 것의 가치라는 뜻으로 정리합니다. 유료 대안의 즐거움 전체를 추가 비용으로 더하거나, 동일한 관람 기회의 가치를 두 축에서 중복해서 더하지 않습니다. 학생은 금액 계산이나 만족의 화폐 환산 없이 돈·시간의 다른 쓰임을 바탕으로 선택을 설명합니다. 가격이나 행사 조건을 바꾸는 활동은 포함하지 않습니다.
