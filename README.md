# 선택의 다른 쪽 · 기회비용 실험실

여러 교사가 수업 상황에 맞춰 사용할 수 있는 중학교 사회 수업용 인터랙티브 콘텐츠입니다. 교사가 앞에서 화면을 조작하며 야구와 콘서트 중 하나를 선택할 때 실제로 쓴 돈과 시간의 다른 쓰임을 차례로 설명합니다.

## 실행

`index.html` 하나를 브라우저에서 엽니다. CSS, JavaScript, SVG 그림이 파일 안에 포함되어 인터넷 연결이나 설치 없이 실행됩니다. GitHub Pages에서도 별도 빌드 없이 사용할 수 있습니다.

## 고정된 상황

같은 토요일 오후에 야구 경기와 콘서트가 열립니다. 각각 관람할 돈은 있지만 이동·관람 시간이 겹쳐 한 곳만 갈 수 있습니다. 지출은 입장료 한 가지로 단순화했으며, 야구는 20,000원, 콘서트는 50,000원으로 정했습니다. 선택 카드와 돈 장면·공개 모달·정리 화면에 같은 가격을 사용합니다.

## 수업 흐름

도입에서는 용돈 봉투가 열리고 지폐가 지갑으로 들어오는 약 4초의 모션그래픽을 자동으로 한 번 재생합니다. 월요일부터 일요일까지 일주일을 표시하며, 용돈 금액은 정하지 않습니다. 용돈 수령 모션과 완료 표시가 끝나면 ‘그 돈을 어디에 사용할까요?’가 나타납니다. ‘모션 다시 보기’를 누르면 질문도 다시 숨겼다가 같은 순서로 표시합니다. ‘활동 살펴보기’로 선택 화면에 들어갑니다. 한 화면의 좌우 두 카드에서 야구와 콘서트를 선택합니다. 선택 카드는 처음에는 정지 상태입니다. 카드를 누르면 그 활동을 선택하고 해당 카드의 모션만 한 번 재생합니다. 야구 카드에서는 타자 뒤의 두 줄 관중석에 18명이 보이고, 공이 맞는 순간에 맞춰 관중들이 뛰며 양손의 응원봉을 흔듭니다. 같은 카드를 다시 누르면 선택과 후속 진행 상태를 유지한 채 모션을 처음부터 다시 재생합니다. 다른 장면에서 돌아왔을 때도 자동 재생하지 않습니다. 자동으로 화면을 넘기지는 않습니다. 시스템의 동작 줄이기 설정에서는 정지 장면으로 표시합니다.

| 장면 | 중심 질문 |
| --- | --- |
| 선택하기 | 토요일 오후, 어디에 가고 싶나요? |
| 돈 살펴보기 | 관람에 실제로 쓴 돈 |
| 시간 살펴보기 | 그 시간, 다른 데에 쓴다면? |
| 기회비용 정리 | 쓴 돈과 포기한 기회를 함께 봐요. |

학생의 응답을 들으며 교사가 카드를 선택하고, 하단의 주요 버튼을 따라 순서대로 내용을 공개합니다. ‘기회비용 정리’에서 내용을 모아 봅니다. 별도의 학생 입력·개별 작성 단계는 없습니다.

## 시간 장면과 차선의 의미

시간 장면에는 왼쪽에 토요일 오후 시간표, 오른쪽에 야구 관람·콘서트 관람·뒹굴거리기·책 읽기·게임하기·친구 만나기 여섯 활동 카드가 있습니다. 시간표는 처음에는 비어 있습니다. 카드를 누르면 해당 활동이 시간표에 들어가고 나머지 다섯 카드에는 X가 표시됩니다. X는 같은 시간에 함께 할 수 없다는 뜻이며, 카드를 다시 누르면 언제든 선택을 바꿀 수 있습니다. 시간 선택은 앞에서 살펴본 관람 입장료 선택과 별도로 탐색하며, 정리 화면에서는 돈과 시간 장면에서 고른 내용을 각각 보여 줍니다.

야구·콘서트는 기존 그림을, 나머지 활동은 이모지를 사용합니다.

‘포기한 기회 보기’는 선택하지 않은 다섯 활동에서 얻었을 가치를 보여 줍니다. 이 중 가장 아쉬운 대안 하나의 가치가 이 시간의 기회비용이며, 다섯 활동의 가치를 합산하지 않습니다.

실제로는 같은 시간에 공부하기, 친구와 놀기 등 여러 대안이 가능할 수 있습니다. 이때는 선택하지 않은 대안 중 가장 가치 있는 대안의 가치를 의사결정에 반영합니다. 서로 다른 대안에서 얻을 가치를 모두 합산하지 않습니다.

## 교사 조작

상단에는 네 단계와 현재 위치를 표시하고, 학습 대상인 카드는 가운데에서 선택합니다. 화면 아래에는 이전 버튼과 현재 할 일을 구체적으로 적은 주요 버튼을 둡니다. 작은 화면에서도 같은 순서와 하단 조작을 유지합니다.

- 하단 버튼으로 순서대로 진행하려면 첫 장면에서 야구 관람 또는 콘서트 관람을 선택합니다. 선택 상태는 색·테두리·체크로 표시합니다.
- ‘쓴 돈 살펴보기’를 누르면 선택한 관람에 실제로 지출한 입장료를 보여 줍니다. 야구는 20,000원, 콘서트는 50,000원입니다. 지갑에서 만 원권이 한 장씩 빠져나가 입장료로 지출되는 모션을 자동으로 한 번 재생합니다. 야구는 2장, 콘서트는 5장이 나가며, ‘모션 다시 보기’로 재생만 다시 할 수 있습니다. 지갑의 남은 잔액은 정하지 않습니다. 동작 줄이기 설정과 설명 모달에서는 정지 그림으로 표시합니다. 저울이나 돈의 다른 쓰임 선택지는 없습니다. ‘명시적 비용 보기’로 실제 지출 금액과 뜻을 모달에서 확인합니다.
- 공개 후 같은 주요 버튼이 ‘시간의 쓰임 살펴보기’로 바뀝니다. 시간 장면에서는 활동 하나를 시간표에 넣고, ‘포기한 기회 보기’로 선택하지 않은 활동에서 얻었을 즐거움과 암묵적 비용의 뜻을 모달로 엽니다.
- ‘얻는 것과 포기하는 것 모아 보기’로 정리 장면에 들어가고, ‘기회비용 정리하기’로 개념을 모달로 엽니다.
- 돈 설명 모달은 선택한 관람의 실제 지출 금액과 명시적 비용의 뜻을 보여 줍니다. 시간 설명 모달은 앞서 본 그림을 재사용해 포기한 다섯 활동을 한 줄의 5열 카드로 보여 줍니다. 각 카드에는 그림·활동 이름·X 표시만 두고, 작은 화면에서는 카드를 가로로 스크롤합니다. 개념은 별도 색상 블록으로 정리합니다. 작은 화면에서는 본문을 스크롤하고 상단 닫기와 하단 ‘닫기’는 항상 보입니다.
- 공개 설명은 ‘닫기’ 또는 Esc로 닫습니다. 닫아도 진행 상태가 유지되며, 장면의 ‘다시 보기’ 버튼으로 같은 설명을 다시 열 수 있습니다. 모달을 닫으면 열었던 버튼으로 키보드 초점이 돌아옵니다.
- 상단의 네 단계는 처음부터 순서와 관계없이 자유롭게 이동할 수 있습니다. 돈 장면에 바로 이동하면 야구 관람에 실제로 쓴 입장료 20,000원을 보여 주고, 시간 장면에 바로 이동하면 빈 시간표에서 활동을 고를 수 있습니다. ‘이전’과 정리 화면의 다시 보기 버튼으로도 이동합니다. 앞 장면의 선택·공개 상태는 유지됩니다.
- 첫 활동을 바꾸면 후속 선택과 공개 상태가 초기화됩니다. 상단 단계 이동은 계속 자유롭게 사용할 수 있습니다.
- 첫 선택 화면의 ‘용돈 받기’로 용돈 도입을 다시 볼 수 있습니다. 마지막 ‘처음부터 다시 하기’로 모든 선택과 공개 상태를 초기화하고 용돈 받기 장면으로 돌아갑니다. 수업 안내에는 진행 방법과 개념 유의사항을 담았습니다.
- 버튼과 카드는 Tab으로 이동하고 Enter 또는 Space로 조작합니다.
- 상태는 페이지가 열려 있는 동안만 유지됩니다. 새로고침하면 초기화되며 외부로 전송되지 않습니다.

## 개념 설명 유의사항

명시적 비용은 실제 지출하는 돈이며 입장료를 예로 듭니다. 암묵적 비용은 자신의 자원을 사용하며 포기한 차선의 가치로, 이 자료에서는 시간의 다른 사용 기회를 통해 살펴봅니다. 두 개념을 돈과 시간에 각각 일대일 대응하는 고정된 등식으로 가르치지 않습니다.

기회비용은 선택 때문에 포기한 기회 중 가장 가치 있는 것의 가치라는 뜻으로 정리합니다. 유료 대안의 만족 전체를 추가 비용으로 더하거나, 동일한 관람 기회의 가치를 두 축에서 중복해서 더하지 않습니다. 실제로 지출한 입장료와 시간의 다른 쓰임을 살펴보며, 가격이나 행사 조건을 바꾸는 활동은 포함하지 않습니다.

## 디자인

큰 질문, 전체 카드 선택, 상단 단계 표시, 하단의 주요 진행 버튼과 연보라 실험실 테마를 적용했습니다. 키보드 포커스와 작은 화면의 세로 배치를 지원합니다. 외부 라이브러리·웹 폰트·분석 도구·학생 정보 수집은 사용하지 않습니다.
