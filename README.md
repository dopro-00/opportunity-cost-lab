# 선택의 다른 쪽 · 기회비용 실험실

여러 교사가 수업 상황에 맞춰 사용할 수 있는 중학교 사회 수업용 인터랙티브 콘텐츠입니다. 교사가 앞에서 화면을 조작하며 야구와 콘서트 중 하나를 선택할 때 돈과 시간의 다른 쓰임을 차례로 설명합니다.

## 실행

`index.html` 하나를 브라우저에서 엽니다. CSS, JavaScript, SVG 그림이 파일 안에 포함되어 인터넷 연결이나 설치 없이 실행됩니다. GitHub Pages에서도 별도 빌드 없이 사용할 수 있습니다.

## 고정된 상황

같은 토요일 오후에 야구 경기와 콘서트가 열립니다. 각각 관람할 돈은 있지만 이동·관람 시간이 겹쳐 한 곳만 갈 수 있습니다. 지출은 입장료 한 가지로 단순화했습니다. 실제 행사나 가격을 재현한 자료가 아닙니다.

## 수업 흐름

| 장면 | 중심 질문 |
| --- | --- |
| 먼저 선택 | 야구를 보러 갈까, 콘서트에 갈까? |
| 돈의 쓰임 | 이 돈으로 다른 무엇을 할 수 있을까? |
| 시간의 쓰임 | 이 시간에 다른 무엇을 할 수 있을까? |
| 함께 판단 | 얻는 것과 포기하는 것을 함께 보면? |

각 교사는 설명과 공개 순서를 수업 상황에 맞게 운영하고, ‘함께 판단’에서 내용을 정리합니다. 별도의 학생 입력·개별 작성 단계는 없습니다.

## 시간 장면과 차선의 의미

두 일정이 겹친다는 점을 보여 준 뒤, 선택하지 않은 다른 대안과 그 대안에서 얻었을 만족을 차례로 공개합니다. 예를 들어 야구 관람을 선택하면 콘서트 관람이 포기한 다른 대안입니다. 콘서트 안의 여러 즐거움 중 하나를 고르게 하지 않습니다.

실제로는 같은 시간에 공부하기, 친구와 놀기 등 여러 대안이 가능할 수 있습니다. 이때는 선택하지 않은 대안 중 가장 가치 있는 대안의 가치를 의사결정에 반영합니다. 서로 다른 대안에서 얻을 가치를 모두 합산하지 않습니다.

## 교사 조작

장면 이동, 공개, 개념 이름, 선택 지우기, 이전·다음, 수업 안내와 전체화면을 오른쪽 패널에 모았습니다. 작은 화면에서는 같은 패널을 자료 아래 오른쪽에 배치합니다. 학습 대상인 선택 카드는 자료 영역에서 조작합니다.

- 첫 선택은 이후 장면에서 함께 살펴보는 예시입니다. 선택하지 않고 건너뛰면 야구 관람을 예시로 표시합니다.
- 돈 장면은 입장료 공개 → 돈의 다른 쓰임 선택 → 포기한 기회 공개 순서입니다.
- 시간 장면은 시간표 공개 → 다른 대안에서 얻었을 가치 공개 순서입니다. 별도의 가치 선택은 없습니다.
- 명시적 비용·암묵적 비용·기회비용의 개념 이름은 별도의 버튼으로 공개합니다.
- ‘함께 판단’은 얻는 가치 → 돈의 다른 쓰임 → 시간의 다른 쓰임 순서로 공개합니다.
- 공개와 다음 장면 이동은 각각 별도로 조작합니다. 오른쪽 조작 패널의 단계 이름이나 ← / → 키로도 이동할 수 있습니다.
- 첫 선택을 바꾸거나 지우면 돈·시간·비교 장면을 새 선택에 맞춰 초기화합니다.
- 수업 안내에서 발문·개념 유의사항·전체 초기화를 확인할 수 있습니다.
- 상태는 페이지가 열려 있는 동안만 유지됩니다. 새로고침하면 초기화되며 외부로 전송되지 않습니다.

## 개념 설명 유의사항

명시적 비용은 실제 지출하는 돈이며 입장료를 예로 듭니다. 암묵적 비용은 자신의 자원을 사용하며 포기한 차선의 가치로, 이 자료에서는 시간의 다른 사용 기회를 통해 살펴봅니다. 두 개념을 돈과 시간에 각각 일대일 대응하는 고정된 등식으로 가르치지 않습니다.

기회비용은 선택 때문에 포기한 기회 중 가장 가치 있는 것의 가치라는 뜻으로 정리합니다. 유료 대안의 만족 전체를 추가 비용으로 더하거나, 동일한 관람 기회의 가치를 두 축에서 중복해서 더하지 않습니다. 금액 계산이나 만족의 화폐 환산 없이 돈·시간의 다른 쓰임을 살펴보며, 가격이나 행사 조건을 바꾸는 활동은 포함하지 않습니다.

## 디자인

큰 질문, 전체 카드 선택, 단계별 공개, 오른쪽에 모은 조작 패널와 연보라 실험실 테마를 적용했습니다. 키보드 포커스와 작은 화면의 세로 배치를 지원합니다. 외부 라이브러리·웹 폰트·분석 도구·학생 정보 수집은 사용하지 않습니다.
