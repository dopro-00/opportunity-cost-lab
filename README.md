# 기회비용 실험실

교사가 앞에서 조작하고 학생들이 함께 보는 45분 수업용 인터랙티브 콘텐츠입니다.

## 실행

`index.html`을 브라우저에서 엽니다. CSS, JavaScript, SVG 그림이 모두 파일 안에 들어 있어 인터넷 연결이나 설치가 필요하지 않습니다.

GitHub Pages에 게시할 때도 `index.html` 하나를 게시 대상 폴더에 올리면 됩니다. 별도의 빌드 명령은 없습니다.

## 수업 구성

1. 자원의 한계: 두 체험을 같은 시간에 할 수 있는지 예측
2. 무료인 선택: 무료여도 포기한 가치가 있음을 확인
3. 참가비 공개: 편익과 실제 지출을 함께 비교
4. A의 기회비용: 다섯 번의 클릭으로 `5 + (6 − 2) = 9만 원` 분해
5. 두 선택 비교: 기회비용과 순편익 비교
6. 조건 바꾸기: A 참가비 0~5만 원의 변화 실험, 기본값 3만 원

선택과 결과 공개, 근거 공개, 다음 장면 이동은 각각 별도의 조작입니다. 위쪽 단계 이름으로 건너뛰거나 이전으로 돌아갈 수 있습니다. 선택·공개 상태는 장면 이동 중 유지되며, 페이지를 새로고침하면 초기화됩니다.

`수업 안내`에 발문, 시간 배분, 모형의 가정과 전체 초기화 기능이 있습니다. ← / → 키로 장면을 이동할 수 있습니다.

## 모형과 용어

두 체험은 같은 2시간에 열리고, 가진 돈은 5만 원입니다. 편익은 한 학생이 만족을 돈으로 평가한 가상 값으로, 받는 현금과 구분합니다. 가격을 바꿔도 편익은 같다고 가정합니다.

| 항목 | A: 도예 | B: 보드게임 |
| --- | ---: | ---: |
| 편익 | 8만 원 | 6만 원 |
| 참가비 | 5만 원 | 2만 원 |
| 암묵적 비용 | 6−2 = 4만 원 | 8−5 = 3만 원 |
| 기회비용 | 9만 원 | 5만 원 |
| 순편익 | −1만 원 | +1만 원 |

순편익은 `편익−기회비용`으로 사용합니다. ‘편익−참가비’ 자체를 순편익이라고 부르지 않습니다. ‘참여하지 않기’는 편익·지출 0으로 두며, 이 사례의 모든 가격 조건에서 두 체험의 ‘편익−참가비’가 양수입니다.

외부 라이브러리, 웹 폰트, 분석 도구, 계정 연동과 학생 정보 수집은 사용하지 않습니다.
